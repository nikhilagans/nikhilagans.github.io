Password-Based Lock System

November 2025 – January 2026

Arduino UNO | C/C++ | IR Receiver | LCD1602 | Breadboarding

I designed and built an embedded password-based locking system using an Arduino UNO. A user enters a password using an infrared remote, while an LCD provides feedback during the authentication process.

I developed the software logic for reading IR inputs, processing the entered digits, and comparing the completed input against the stored password. The program then determines whether access should be accepted or rejected.

I also assembled and debugged the physical circuit on a breadboard, connecting the Arduino, IR receiver, and LCD. This project gave me experience troubleshooting both hardware connections and software behavior.

Key Concepts

  • Embedded programming
  • Hardware and software integration
  • IR input processing
  • LCD interfacing
  • Breadboard prototyping
  • Hardware debugging

Tic-Tac-Toe in LC-3 Assembly

November 2025

LC-3 Assembly | Memory-Mapped I/O | Graphics | Subroutines

I developed a two-player Tic-Tac-Toe game entirely in LC-3 assembly. Players enter their moves through keyboard input, and the program validates each move before updating the game state.

I stored the state of the board in memory and used subroutines to separate different parts of the program, including receiving input, validating moves, updating the board, and controlling game flow.

I also used the LC-3's memory-mapped display to create a graphical representation of the game board. This required working directly with memory addresses to determine where graphical elements should appear on the screen.

Key Concepts

  • Assembly-language programming
  • Memory addressing
  • Memory-mapped I/O
  • Subroutines
  • Control flow
  • Array-based state tracking
  • Low-level graphics
